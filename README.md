# 📖 About

**TimeEconomyPlugin** is a custom Minecraft plugin developed by **SpectroDinner DEV**, the software development branch of **SpectroDinner™**.

The project is built using **Java 21** and **Paper API**, focusing on creating a modular gameplay ecosystem with custom systems, scalable architecture and maintainable code.

Unlike traditional Minecraft server setups based on many unrelated plugins, TimeEconomyPlugin aims to provide an integrated framework where different gameplay systems work together while maintaining performance, flexibility and future expansion possibilities.

Current development focuses on creating reliable systems that improve Minecraft server experiences while keeping clean architecture and professional software practices.

# 🛠️ Installation

## Requirements

Before installing TimeEconomyPlugin, make sure your server meets these requirements:

- ☕ Java 21+
- 🎮 Minecraft 1.21+
- 🔧 Paper Server
- 📦 TimeEconomyPlugin release file
- 👥 Citizens plugin

---

## Installation Steps

1. Download the latest release from GitHub.
2. Place the `.jar` file inside your server's `plugins` folder.
3. Start or restart your Minecraft server.
4. Configure the plugin if required.
5. Enjoy TimeEconomyPlugin.

# 🏗️ Building From Source

Developers can build TimeEconomyPlugin using Maven.

---

## Clone Repository

```bash
git clone https://github.com/Elmoderador/TimeEconomyPlugin.git
```

---

## Enter Project Directory

```bash
cd TimeEconomyPlugin
```

---

## Build Plugin

```bash
mvn clean package
```

The generated `.jar` file will be located inside:

```text
target/
```
